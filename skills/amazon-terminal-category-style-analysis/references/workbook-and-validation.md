# 工作簿与验证规范

## 款式工作簿

每个款式至少包含：

1. `款式结论`：规模、中位数、难度、机会优先级、支持与反对证据、敏感性结果。
2. `新品表现`：新品分层、成功率、历史表现、成功与失败案例。
3. `产品明细`：全部有销量父体 Listing、分类标签、置信度、证据和主图。
4. `头部竞品`：成熟头部与新品头部的对照。
5. `趋势与分布`：月度趋势、价格、评论、品牌和集中度图表。
6. `分类依据与来源`：规则版本、来源、假设、权重、缺失和局限。

总览工作簿应按机会优先级排序，同时保留进入难度、市场体量、新品指标、结论稳定性、主要反对证据和独立工作簿名称。

## 图片

- 缓存同一 ASIN 的主图，转换为受控尺寸和质量的 JPEG/PNG 缩略图。
- 在产品明细、头部竞品和新品案例中嵌入单元格区域，并保留原图 URL 与 Amazon 链接。
- 固定行高和图片锚点，保证筛选与浏览时图片和 ASIN 对应。
- 下载失败显示“图片不可用”，但不终止整批生成。

## 可追溯输出

每次运行保存：原始数据、来源与采集信息、清洗排除清单、分类结果和置信度、配置、规则版本、评分权重、输出清单和校验报告。输出使用站点、类目、月份和版本组成的目录，不覆盖旧版本。

## 必须验证

- ASIN 无重复归类，款式汇总与清洗后总体一致。
- 独立复算销量、销售额、价格中位数、新品分层、成功率、集中度、三场景难度和机会优先级。
- 执行剔除 Top1 测试以及新品定义、阈值和权重敏感性测试。
- 抽查各款式头部、新品、低销量和低置信度商品的图片、标题与分类。
- 检查图片缺失、日期缺失、价格缺失和历史覆盖不足等边界情况。
- 重新计算并扫描全部工作簿，确保无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 等错误。
- 渲染总览、所有结论页、新品页和趋势页，并分段抽查长明细表。
- 检查筛选、冻结窗格、列宽、行高、数字格式、长文本换行和 WPS/Excel 兼容性。

交付时报告工作簿数量、纳入与排除数量、重复 ASIN 数、图片成功率、公式错误数和已知数据局限。
