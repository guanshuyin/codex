# 数据与分类流程

## 样本口径

款式发现以类目内月销量大于 0 的全部有效父体 Listing 为主；Top 100 用于深度竞争分析，但不能代替全量样本，否则会放大幸存者偏差并丢失长尾与新兴款式。

优先抓取：父 ASIN、标题、品牌、卖家、价格、月销量、月销售额、BSR、评分、评论数、上架日期、履约方式、变体数量、主图、尺寸、重量和历史月度趋势。

## 清洗

- 按父体 Listing 去重，保留子体数量作为复杂度指标。
- 排除销量为 0、不可售、配件、误分类及无法确认属于主体商品的 Listing。
- 排除规则须按类目配置，并保存 ASIN、原始字段和排除原因。
- 有效正价格才参与均价与中位数计算。
- 日期、销量或价格异常不能静默修正；保留原值、标记异常并说明是否参与计算。

## 款式发现与归类

以产品主体结构和核心用途为第一判断依据。人数、季节、场景、搭建方式、层数、重量和特殊功能为辅助标签。

建议顺序：

1. 从标题、类目属性和主图发现候选结构。
2. 建立包含词、排除词、冲突规则和优先级的类目词典。
3. 用规则初分，并记录命中证据与置信度。
4. 抽查头部、腰部、新品、低销量和低置信度样本。
5. 合并商业意义相近的小类，拆分结构、价格带和购买需求明显不同的大类。
6. 样本过小且销量贡献低的款式可合并进“其他/待确认”，但不得强行得出进入结论。

标题、属性和图片冲突时，以主体结构与核心用途为准；无法确认时降低置信度并进入人工复核队列。关键词命中本身不是充分证据。

## 分类质量门槛

- 一个 ASIN 只能出现于一个主款式。
- 分类汇总的商品数、销量和销售额必须与清洗后的总体一致。
- 保存原分类、调整后分类、调整原因、证据和规则版本。
- 新月份运行时检查词典漂移、新结构、新用途和异常增长款式。
