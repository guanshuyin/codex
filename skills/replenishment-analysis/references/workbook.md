# 工作簿整理与交付

## 标准结构

| 子表 | 内容 |
|---|---|
| Sheet1 | 历史销量、实际／预测标记、库存、在途、SKU 和 ASIN |
| Sheet2 | 库存分类、覆盖期、缺口和分类依据 |
| Sheet3 | SKU 月度需求及预测日均单量 |
| Sheet4 | 第一、二类 SKU 的采购／发货事件及事件前后库存 |
| Sheet5 | 市场与竞品数据源、趋势、权重和计算口径 |

用户仅要求某一步时，只新增或更新必要子表。覆盖下游子表前确认其使用的是当前版本需求。

## Sheet1 规则

- 忠实合并源数据，不凭空增加 SKU，不静默删除重复或异常记录。
- 标准化 SKU、ASIN、站点、年月、销量、数据性质和库存字段。
- 同一 SKU 同月多行须判断是国家拆分、订单拆分还是重复；合计前保留核对依据。
- 用户对“实际／预测”的说明优先于单元格标签，并在备注中记录口径转换。

## 格式与兼容性

- 使用中文表头、真实数值和真实日期；月份统一为 `yyyy-mm` 或该月首日。
- 不默认冻结窗格。
- 避免外部链接、动态数组和 WPS 兼容性不明的新函数。
- 非必要时写入已计算静态值；必须保留公式时，同时提供口径说明。
- 使用条件格式突出分类、缺口、断货和待确认项，但不要过度装饰。
- 列宽、换行、小数位和日期格式应在渲染后可读。

## 交付检查

- 扫描 `#VALUE!`、`#NAME?`、`#REF!`、`#DIV/0!`、`#N/A`。
- 核对 Sheet1 唯一 SKU 数与 Sheet2、Sheet3 一致；Sheet4 只含第一、二类。
- 核对月需求与日均单量之间的天数换算。
- 渲染关键工作表并检查截断、错列、隐藏行列和异常冻结。
- 不覆盖桌面源文件；输出至项目 `outputs/<任务名>/`。
