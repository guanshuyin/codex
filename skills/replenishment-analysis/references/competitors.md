# 竞品搜集与筛选

## 数据获取顺序

1. 卖家精灵 MCP；
2. Softtime MCP；
3. SIF MCP；
4. Amazon 商品页及其他可信公开来源作补充或交叉验证。

接口存在时先使用接口，不以普通网页搜索替代结构化数据。记录站点、ASIN、抓取日期、价格、上架时间、尺寸、结构、容量、销量／BSR 和数据完整性。

## 匹配优先级

1. 真正的自弹／抛开式结构；
2. 展开尺寸和容纳人数；
3. 使用场景与内部空间；
4. 价格带和市场定位；
5. 上架阶段、评论积累和销量可比性；
6. 颜色仅为次要因素。

液压／伞状速开帐、普通圆顶帐、隧道帐、沙滩帐、隐私／厕所帐不能作为直接竞品。伞状帐最多作为低权重间接竞品。

## 可靠性判断

为每个候选标记：直接竞品、间接竞品、排除、待确认。至少核对商品图、结构描述和尺寸，不能只看标题。

以下任一情况应降权或剔除：

- 结构或尺寸明显不匹配；
- 历史月份太少；
- 销量长时间为 0／1 或存在明显断货；
- 变体合并、站点迁移或数据口径不一致；
- 价格层级或用途显著不同。

竞品趋势可由多个合格 ASIN 的同比变化经中位数或按可靠性加权得到。不要让单一爆款或异常商品代表整个系列。
